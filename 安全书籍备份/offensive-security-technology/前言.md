# 前言

高中毕业后，我的人生计划是成为一名私人侦探，也许是因为我读了太多夏洛克·福尔摩斯的书。在法国，成为私人侦探最简单的方法是（曾经是？）先上法律大学，然后进入专门的学校。

我还没有准备好。

我很快意识到学习法律不适合我：现实被歪曲以适应政治或教授希望我们相信的任何叙述。这里没有教授深层知识，只有数字、日期、如何看起来体面和听起来聪明。对于当时充满无尽好奇心的年轻人来说，这是极其令人沮丧的。我想了解世界是如何运作的，而不是人类的惯例。例如，我们整天疯狂敲击的这些被称为计算机的机器在底层是如何工作的？

所以我开始在我的华硕EeePC上安装Linux（不，我不会参与GNU/Linux之争），这是一台只有1GB内存的小型上网本，因为Windows太慢了，并开始通过在线教程学习用Qt开发C++程序。我编写了自己的文本编辑器和聊天系统。但我的好奇心仍未得到满足。

有一天，我无意中发现了改变我人生的书：Jon Erickson的《黑客攻防技术揭秘，第2版》。

这本书不仅让我对如何制造东西产生了好奇心，更重要的是，对如何破坏东西产生了好奇心。它让我意识到，如果不了解如何破坏事物，以及它们的弱点在哪里，就无法构建可靠的东西。

虽然这本书在学习底层编程和如何利用简单的内存安全漏洞方面仍然很棒，但今天，黑客攻击需要新的技能：Web漏洞利用、网络和系统编程，最重要的是，如何用现代编程语言编程。

欢迎来到Rust和进攻性安全的迷人世界。

虽然《Rust程序设计语言》在教授"什么是Rust"方面做得很好，但我觉得缺少一本关于"为什么和如何使用Rust"的书。这意味着本书不会深入涵盖某些概念。相反，我们将看到如何在实践中有效地使用它们。

在这本书中，我们将打破先入为主的观念（Rust对现实世界来说太复杂了，Rust不够高效...），看看如何架构和创建应用于进攻性安全的真实世界Rust项目。我们将看到Rust是多么多才多艺，它使用户能够用一种独特的语言替换困扰进攻性安全世界的大量编程语言（Python、Ruby、C、C++...），这种语言提供高级抽象、高性能，以及在需要时的底层控制。

我们总是从一些理论开始，这些深层知识跨越时代、技术和趋势。这些知识独立于任何编程语言，将帮助你获得进攻性安全所需的正确心态。

我为那些想要了解攻击者思维以更好地保护自己的人，或者想要进入进攻性安全世界并最终以此为生的人设计了这本书。

这本书的目标是通过提炼知识并在应用代码项目中呈现它们，为你节省行动路径上的时间。

重要的是要理解《进攻性安全技术》并不意味着成为一本包含世界所有知识的大百科全书。相反，它被设计为一个指南，帮助你入门并为行动铺平道路。知识通常是先决条件，但塑造世界的是行动，有时知识是行动的阻碍（见分析瘫痪）。正如我们将看到的，一些最原始的进攻技术仍然是最有效的。因此，一些非常具体的主题，比如如何绕过现代操作系统保护机制，不会被涵盖，因为这些主题已经有大量文献，而且它们在一本关于Rust的书中价值有限。

话虽如此，我尽力列出了进一步学习之旅的最佳资源。

我花了大约1年时间才在Rust中变得高效，但只有当我开始编写（和重写）大量代码时，我才取得了真正的进步。

Rust是一门极其庞大的语言，但实际上，你将（也应该）只使用其功能的一个子集：你不需要提前学习所有功能。我们将在本书中学习的一些功能是基础的。其他的则不是，可能会通过使代码更难阅读和维护而对代码质量产生不利影响。

我写这本书的目的不仅是让你发现进攻性安全的精彩世界，说服你Rust是期待已久的一站式编程语言，满足进攻性安全的所有需求，而且还要通过指导你学习Rust和进攻性安全时真正重要的内容来为你节省大量时间。但请记住，知识是不够的。知识不能移山。行动才能。

因此，这本书只是故事的一半。另一半是配套的代码仓库：`https://github.com/skerkour/black-hat-rust`。没有实践就不可能学会，所以我邀请你阅读代码，修改它并使其成为你自己的！

如果在任何时候你感到迷茫或不理解某段Rust代码，请不要犹豫参考Rust语言速查表、《Rust程序设计语言》和Rust语言参考。

此外，这本书代码量很大。我建议你在阅读时打开一个网页浏览器，以便在GitHub上探索和使用代码：`https://github.com/skerkour/black-hat-rust/`。
